# Лабораторная работа: банковские транзакции

## Описание

Приложение на PHP демонстрирует объектно-ориентированную работу с банковскими транзакциями. Можно добавлять и удалять записи, искать их по дате, сортировать по сумме и просматривать результаты вычислений. Таблица отображается в HTML, а транзакции сохраняются в `transactions.txt`.

Основные классы:

- `Transaction` — данные одной транзакции.
- `TransactionStorageInterface` — общий интерфейс хранилища.
- `TransactionRepository` — добавление, удаление и хранение транзакций в файле.
- `TransactionManager` — поиск, сортировка и вычисления.
- `TransactionTableRenderer` — вывод транзакций в HTML-таблице.

## Запуск

Из папки `lab5Cascaval` запустите встроенный веб-сервер PHP:

```bash
php -S localhost:8000
```

Откройте в браузере `http://localhost:8000`. При первом запуске приложение создаст файл с начальными транзакциями.

## Контрольные вопросы

1. **Зачем нужна строгая типизация в PHP?**  
   легче найти ошибки типов.

2. **Что такое класс?**  
   Класс - описание объектов. Он содержит свойства для данных и методы для действий с этими данными. Объект — конкретный экземпляр класса.

3. **Что такое полиморфизм?**  
   наследыване.

4. **Что такое интерфейс и чем он отличается от абстрактного класса?**  
   Интерфейс задаёт методы, которые класс обязан реализовать. Абстрактный класс может также содержать свойства, готовые методы и общее состояние. Класс может реализовать несколько интерфейсов, но наследоваться только от одного класса.

5. **Зачем нужны интерфейсы?**  
   Они уменьшают зависимость кода от конкретной реализации.
