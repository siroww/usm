Импортируйте класс **Scanner** для использования объекта Scanner, как показано здесь:

```java
import java.util.Scanner; 
```

Чтобы использовать класс Scanner, создайте экземпляр класса, используя следующий синтаксис:

```java
Scanner sc = new Scanner(System.in);
```

Теперь вы можете читать различные виды входных данных, которые вводите. При этом имя объекта можно задать произвольно (не обязательно sc).  
Вот некоторые методы, доступные через класс Scanner:

Ввести объект int: **nextInt()**  
Ввести объект float: **nextFloat()**  
Ввести объект double: **nextDouble()**  
Ввести объект boolean: **nextBoolean()**  
Ввести строку целиком: **nextLine()**  
Ввести слово (считывается до первого пробела): **next()**

Пример программы, используемой для получения пользовательского ввода:

```java
import java.util.Scanner;

class MyClass {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println(sc.nextLine());
    }
}
```

Чтобы получить несколько объектов данных с входящего потока, достаточно одного объекта сканера. Единственный сканер может обрабатывать входные данные различных типов:

```java
import java.util.Scanner;

class MyClass {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int x = sc.nextInt();
        double y = sc.nextDouble();
        String s = sc.nextLine();
    }
}
```


Задаче: 
```java
import java.util.Scanner; 

class MySolution { 
public static void main(String[] args) { 
Scanner sc = new Scanner(System.in); 
int a = sc.nextInt(); 
String b = sc.nextLine(); 
int c = sc.nextInt(); 
System.out.println(c+":"+b+":"+a); } 
}
```

**Шаг 1** — вводишь год `2021`, `nextInt()` читает `2021`, Enter остаётся в буфере.

```
a = 2021
Буфер: ['\n']
```

**Шаг 2** — `nextLine()` должен прочитать месяц `01`. Но видит оставшийся Enter и читает пустую строку.

```
b = ""
Буфер пуст
```

**Шаг 3** — вводишь месяц `01`, но `nextInt()` читает его как число и отбрасывает ноль спереди.

```
c = 1
```

Итог:

```
c + ":" + b + ":" + a
1  + ":" + "" + ":" + 2021
= "1::2021"  ← вот твой ответ!
```

---

По сути у тебя две проблемы сразу — и съеденный Enter, и перепутанный порядок переменных. Задание просит ввести год → месяц → день, а у тебя `c` это третья переменная (день), но ты читаешь в неё месяц.

`nextInt()` читает только само число и **останавливается прямо там**. Курсор остаётся на той же строке после числа.

Вот наглядно:

```
2021\n01\n30
    ^
    nextInt() прочитал "2021" и встал сюда
```

А `\n` — это и есть Enter, он остался в буфере. И когда следующим идёт `nextLine()` — он видит этот `\n` и думает что строка закончилась, возвращает пустую строку и переходит дальше.

```
2021\n01\n30
     ^
     nextLine() увидел \n и вернул "" — пустую строку
```

Вот почему `30` не терялся — он просто читался не той переменной и не в то место. В твоём случае `c = nextInt()` читал `01` и превращал его в `1`.


## 📑 ШПАРГАЛКА ПО SCANNER В JAVA

> Главное правило: Компьютер видит твой ввод как ленту символов. Пробел (`_`) и Enter (`\n`) для него — это просто невидимые знаки на этой ленте.

---

## 🛠 Краткая суть методов

| Метод                                                                                                      | Что ищет на ленте | Как реагирует на пробелы и Enter (`\n`)                                                      | Что оставляет после себя         |
| ---------------------------------------------------------------------------------------------------------- | ----------------- | -------------------------------------------------------------------------------------------- | -------------------------------- |
| `nextInt()`  <br>`nextDouble()`, `nextLong()`, `nextShort()`, `nextByte()`, `nextFloat()`, `nextBoolean()` | Только цифры      | Перепрыгивает их в начале.  <br>Останавливается перед ними в конце.                          | Оставляет `_` или `\n` на ленте. |
| `next()`                                                                                                   | Одно слово        | Перепрыгивает их в начале.  <br>Останавливается перед ними в конце.                          | Оставляет `_` или `\n` на ленте. |
| `nextLine()`                                                                                               | Всю строку        | Не перепрыгивает.  <br>Ищет первый `\n`, забирает всё до него, а сам `\n` удаляет (съедает). | Оставляет ленту чистой.          |

---

## 🚀 Визуальный разбор на примерах кода

## Пример 1. Ввод чисел через пробел или Enter (Работа `nextInt()`)

Код:

```java
int a = sc.nextInt();
int b = sc.nextInt();
```

- Вариант ввода А (в одну строку): `5 10` _(между ними два пробела)_
    
    - Лента изначально: `5__10\n`
    - Шаг 1 (`a`): `nextInt()` берет `5`. Останавливается перед пробелом. _На ленте:_ `__10\n`
    - Шаг 2 (`b`): `nextInt()` перепрыгивает два пробела, берет `10`. _На ленте остается:_ `\n`
    
- Вариант ввода Б (на разных строках):
    
    ```text
    5
    10
    ```
    
    - Лента изначально: `5\n10\n`
    - Шаг 1 (`a`): `nextInt()` берет `5`. _На ленте осталось:_ `\n10\n`
    - Шаг 2 (`b`): `nextInt()` перепрыгивает перенос строки `\n`, берет `10`. _На ленте:_ `\n`
    

> Вывод: Числовым методам (и методу `next()`) абсолютно плевать, разделяешь ты данные пробелом или кнопкой Enter. Они пролетят сквозь них и найдут данные.

---

## Пример 2. Чтение слов (Работа `next()`)

Код:

```java
String word1 = sc.next();
String word2 = sc.next();
```

- Ввод в консоль: `Java Dev`
- Лента изначально: `Java__Dev\n`
- Шаг 1 (`word1`): `next()` забирает букву за буквой до первого пробела ➔ сохраняет `"Java"`. _На ленте осталось:_ `__Dev\n`
- Шаг 2 (`word2`): `next()` перепрыгивает пробелы, забирает `"Dev"`. _На ленте осталось:_ `\n`

---

## Пример 3. Чтение всей строки (Работа `nextLine()`)

Код:

```java
String sentence = sc.nextLine();
```

- Ввод в консоль: `Я люблю Java!`
- Лента изначально: `Я_люблю_Java!\n`
- Как работает: `nextLine()` идет напролом. Ему плевать на пробелы. Он гребет всё до знака `\n`.
- Результат: В переменную запишется `"Я люблю Java!"`, а сам символ `\n` робот сотрет с ленты. Лента пуста.

## 🚨 Главная ловушка: Смешивание методов (Число ➔ Строка)

Код С БАГОМ (Так делать НЕЛЬЗЯ):

```java
System.out.print("Введите возраст: ");
int age = sc.nextInt(); 

System.out.print("Введите имя: ");
String name = sc.nextLine(); // ❌ Программа проскочит этот ввод!
```

- Что происходит в консоли:
    
    1. Ты вводишь `25` и жмешь Enter.
    2. Лента принимает вид: `25\n`
    3. `nextInt()` забирает `25`. Но Enter (`\n`) остается лежать на ленте!
    4. Очередь доходит до `nextLine()`. Он смотрит на ленту, а там первым же символом лежит `\n`.
    5. `nextLine()` думает: _"О, перенос строки! Значит, текст закончился"_. Он съедает этот `\n`, а в переменную `name` записывает пустоту `""`. Ты даже не успеваешь ничего набрать.
    

## 🛠 Как это починить (2 способа):

Способ 1: Добавить «холостой» вызов (Самый частый вариант)  
Мы принудительно заставляем один `nextLine()` сработать впустую, чтобы просто убрать мусорный Enter с ленты.

```java
int age = sc.nextInt(); 
sc.nextLine(); // 🔥 Холостой вызов! Просто "кушает" оставшийся \n и очищает ленту
String name = sc.nextLine(); // Теперь всё работает, консоль ждет ввода имени!
```

Способ 2: Читать всё через строку (Самый профессиональный вариант)  
Чтобы лента никогда не забивалась хвостами, мы всегда читаем строки через `nextLine()`, а если нам нужно число — сами превращаем строку в число.

```java
int age = Integer.parseInt(sc.nextLine()); // Читает "25\n", съедает \n, превращает "25" в число
String name = sc.nextLine(); // Лента была идеальной чистой, ввод работает четко!
```

---

## 💡 Золотые правила для сохранения:

1. Если на вход подаются данные в одну строчку через пробел или строго по одному слову/числу на строку ➔ используй `nextInt()`, `nextDouble()`, `next()`. Они сами перешагнут через все пробелы и энтеры.
2. Если тебе нужно ввести текст с пробелами (ФИО, адрес, предложение) ➔ используй `nextLine()`.
3. Если ты используешь `nextLine()` ПОСЛЕ любого другого метода (`nextInt`, `next` и т.д.) ➔ обязательно ставь между ними холостой `sc.nextLine()`.
