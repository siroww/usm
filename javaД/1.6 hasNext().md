## Общая идея

`hasNext...()` — это методы которые **проверяют**, есть ли ещё данные для чтения, **без того чтобы их забирать**. Они отвечают просто `true` или `false`, и сам Scanner после проверки остаётся на том же месте — данные никуда не "съедаются".

Главное применение — **проверка перед чтением**, чтобы избежать ошибок типа `InputMismatchException` (как у тебя было с прямоугольником, когда подали дробное число в `nextInt()`).

---

## 1. hasNext() — есть ли вообще ещё хоть что-то

Метод hasNext() возвращает true, если есть ещё хотя бы один токен в Scanner. hasNext() использует разделитель (delimiter) чтобы проверить наличие следующего токена — то есть он смотрит, есть ли впереди ещё какое-то "слово" (последовательность символов без пробелов).

```java
Scanner myObj = new Scanner("A string to scan");

while (myObj.hasNext()) {
    System.out.println(myObj.next());
}
```

**Результат:**

```
A
string
to
scan
```

Цикл проверяет `hasNext()` перед каждой итерацией, и как только токенов больше не остаётся — `hasNext()` вернёт `false`, и цикл сам остановится. Это удобнее чем заранее знать сколько именно слов будет вводиться.

---

## 2. hasNextInt() — это будет целое число?

hasNextInt() возвращает true если следующий токен представляет число, которое можно сохранить в тип int — то есть любое целое число от -2 147 483 648 до 2 147 483 647.

```java
Scanner sc = new Scanner(System.in);

if (sc.hasNextInt()) {
    int number = sc.nextInt();
    System.out.println("Это число: " + number);
} else {
    System.out.println("Это не целое число!");
}
```

**Главное применение — защита от ошибки**, которая у тебя была в задаче про прямоугольник:

```java
Scanner sc = new Scanner(System.in);
System.out.print("Введи целое число: ");

if (sc.hasNextInt()) {
    int n = sc.nextInt();
    System.out.println("Получено: " + n);
} else {
    System.out.println("Это не похоже на целое число, программа не сломалась!");
}
```

Если пользователь введёт `5.5` или `привет` вместо числа — программа **не вылетит с ошибкой**, а просто скажет что это не подходит. Без проверки `hasNextInt()` твоя программа упала бы с `InputMismatchException`, как было в задаче с прямоугольником.

---

## 3. hasNextDouble() — это будет дробное число?

Работает абсолютно так же, но проверяет возможность прочитать `double`:

```java
Scanner sc = new Scanner(System.in);
System.out.print("Введи число: ");

if (sc.hasNextDouble()) {
    double d = sc.nextDouble();
    System.out.println("Дробное число: " + d);
} else {
    System.out.println("Это не число!");
}
```

⚠️ Важный нюанс: `hasNextDouble()` тоже вернёт `true` для **целых** чисел, потому что целое число можно прочитать как `double` без проблем (`5` спокойно становится `5.0`). А вот `hasNextInt()` вернёт `false` для `5.5`, потому что дробная часть не влезает в `int`.

---

## 4. hasNextLine() — есть ли ещё хоть одна строка

hasNextLine() возвращает true, если есть ещё одна строка текста доступная в Scanner. hasNextLine() проверяет есть ли ещё строка во вводе, независимо от того пустая она или нет — то есть даже пустая строка (просто Enter без текста) всё равно считается "ещё одной строкой".

**Самое частое применение — чтение файла целиком, строка за строкой:**

Стандартный паттерн для чтения файла: открываем сканер на файле, и в цикле while проверяем hasNextLine(), внутри читаем nextLine():

```java
import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class ReadFile {
    public static void main(String[] args) {
        try {
            File myObj = new File("filename.txt");
            Scanner myReader = new Scanner(myObj);
            
            while (myReader.hasNextLine()) {
                String data = myReader.nextLine();
                System.out.println(data);
            }
            myReader.close();
        } catch (FileNotFoundException e) {
            System.out.println("Файл не найден.");
        }
    }
}
```

Этот же паттерн работает и для чтения с клавиатуры — цикл продолжается пока есть что читать, и сам останавливается когда строки закончились (например пользователь нажал Ctrl+D или ввод из файла закончился).

## 5. ⚠️ Главная разница — hasNext() vs hasNextLine()

Это очень частый источник путаницы, давай разберём чётко.

hasNextLine() проверяет есть ли ещё строка во вводе (пустая она или нет), в то время как hasNext() использует разделитель чтобы проверить наличие следующего токена.

**Главное отличие:**

|Метод|Что считает|Пробелы внутри|
|---|---|---|
|`hasNext()`|Следующее **слово** (токен) до пробела/Enter|Останавливается на пробеле|
|`hasNextLine()`|Следующую **строку целиком** до Enter|Включает пробелы внутри строки|

**Наглядный пример:**

```java
Scanner sc = new Scanner("Привет мир\nПока");

System.out.println(sc.hasNext());     // true
System.out.println(sc.next());        // "Привет" (только до пробела!)

System.out.println(sc.hasNextLine()); // true
System.out.println(sc.nextLine());    // " мир" (всё что осталось до конца строки)
```

`next()` взял только первое слово `"Привет"`, оставив `" мир"` нетронутым. А `nextLine()` после этого забрал всё что осталось до конца текущей строки.

## 6. Полный список hasNext-методов

У Scanner есть методы: hasNextBigDecimal(), hasNextBigInteger(), hasNextBoolean(), hasNextByte(), hasNextDouble(), hasNextFloat(), hasNextInt(), hasNextLine(), hasNextLong(), hasNext(), hasNextShort().

Полная таблица, какой `hasNext` к какому `next` относится:

|Проверка|Чтение|
|---|---|
|`hasNext()`|`next()`|
|`hasNextLine()`|`nextLine()`|
|`hasNextInt()`|`nextInt()`|
|`hasNextDouble()`|`nextDouble()`|
|`hasNextLong()`|`nextLong()`|
|`hasNextFloat()`|`nextFloat()`|
|`hasNextBoolean()`|`nextBoolean()`|
|`hasNextByte()`|`nextByte()`|
|`hasNextShort()`|`nextShort()`|

Логика одинаковая для всех — `hasNextX()` проверяет можно ли безопасно прочитать через `nextX()`, без риска вылететь с ошибкой.

## 7. Практический паттерн — читаем числа пока они идут

Классический пример использования из официальной документации Oracle:

Этот код позволяет читать значения типа long из элементов файла myNumbers: while (sc.hasNextLong()) { long aLong = sc.nextLong(); }

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int sum = 0;
        
        System.out.println("Вводи числа (любой не-число завершит ввод):");
        
        while (sc.hasNextInt()) {
            int num = sc.nextInt();
            sum += num;
        }
        
        System.out.println("Сумма: " + sum);
    }
}
```

Программа будет складывать числа **до тех пор**, пока пользователь вводит числа. Как только введёт что-то не числовое — цикл сам остановится, без падения программы.

## 8. Глубина — паттерн "проверь и пропусти"

Хороший практический пример: создаём сканер из строки с разными словами, и в цикле проверяем — если hasNextInt() true, печатаем число через nextInt(), иначе просто пропускаем токен через next():

```java
Scanner myObj = new Scanner("Число 1 это число, а слово два — не число 2");

while (myObj.hasNext()) {
    if (myObj.hasNextInt()) {
        System.out.println("Нашли число: " + myObj.nextInt());
    } else {
        myObj.next(); // просто пропускаем слово, не сохраняя его
    }
}
```

**Результат:**

```
Нашли число: 1
Нашли число: 2
```

Это мощный паттерн — программа "фильтрует" входные данные, выбирая только то, что подходит под нужный тип, и просто перешагивая через остальное.

⚠️ **Важная деталь:** обязательно вызывай `next()` в `else` блоке (или другой `nextX()` метод), а не просто `continue` — иначе ты создашь **бесконечный цикл**, потому что Scanner будет стоять на том же месте вечно, проверяя один и тот же токен снова и снова.

---

## 9. Зачем это всё нужно — главный практический смысл

Возвращаясь к твоей задаче с прямоугольником — вот как `hasNextDouble()` сделал бы код **безопасным**:

```java
import java.util.Scanner;

public class MyNumber {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        if (sc.hasNextDouble()) {
            double x = sc.nextDouble();
            
            if (sc.hasNextDouble()) {
                double y = sc.nextDouble();
                double area = x * y;
                double per = 2 * (x + y);
                System.out.println(area + "\n" + per);
            } else {
                System.out.println("Второе число некорректно!");
            }
        } else {
            System.out.println("Первое число некорректно!");
        }
    }
}
```

Хотя для конкретно этой задачи на Stepik (где формат входных данных гарантирован) это избыточно — но в **реальных программах**, где пользователь может ввести что угодно, такая защита через `hasNextX()` — это стандартная практика, а не "лишний код".

## Итоговая таблица — главное что нужно запомнить

|Метод|Возвращает true если...|
|---|---|
|`hasNext()`|есть ещё хоть одно слово (токен)|
|`hasNextLine()`|есть ещё хоть одна строка (даже пустая)|
|`hasNextInt()`|следующий токен можно прочитать как целое число|
|`hasNextDouble()`|следующий токен можно прочитать как дробное число|

**Главное правило:** перед каждым `nextX()`, если не уверен в формате входных данных — сначала проверь через `hasNextX()`, чтобы не получить `InputMismatchException`.
