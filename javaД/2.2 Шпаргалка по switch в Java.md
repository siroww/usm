
Оператор `switch` — это альтернатива куче блоков `if-else if-else`, когда нужно сравнивать **одну переменную с конкретными значениями**.
## 1. Базовый синтаксис (Классика Java 7 и выше)

В классическом `switch` программа ищет совпадение и выполняет код сверху вниз. Символ `:` обязателен после каждого `case`.

Java

```java
switch (переменная) {
    case значение1:
        // Код, если переменная == значение1
        break; // Выход из switch
    case значение2:
        // Код, если переменная == значение2
        break;
    default:
        // Код, если ни одно значение не подошло (аналог else)
        break; // В default break писать необязательно, но желательно для порядка
}
```

### 🧱 Какие типы данных можно совать в `switch`?

- **Целые числа:** `byte`, `short`, `char`, `int`.
    
- **Обёртки:** `Byte`, `Short`, `Character`, `Integer`.
    
- **Строки:** `String` (работает начиная **с Java 7**!).
    
- **Перечисления:** `Enum`.
    

❌ **НЕЛЬЗЯ использовать:** `long`, `float`, `double`, `boolean` и любые обычные объекты.

## 2. Секреты ключевого слова `break` и "Проваливание" (Fall-through)

Если забыть написать `break`, Java не остановится на найденном кейсе, а пойдет выполнять код всех следующих кейсов подряд, пока не встретит `break` или конец `switch`. Это называется **проваливанием**.

### 🛠 Как использовать проваливание с пользой (Группировка кейсов)

#### Вариант 1: Столбиком (Классический стиль)

Удобно, если нужно, чтобы несколько условий вызывали один и тот же код.

Java

```java
switch (month) {
    case 1:
    case 2:
    case 12:
        System.out.println("Зима");
        break; // Остановит выполнение здесь
}
```

#### Вариант 2: В одну строчку (Для компактности в Java 7)

Абсолютно то же самое, но экономит место на экране.

```java
switch (month) {
    case 1: case 2: case 12:
        System.out.println("Зима");
        break;
}
```

## 3. Ошибки и ограничения (⚠️ Важно для тестов!)

- **Ловушка дубликатов:** Нельзя создавать два одинаковых кейса. Код `case 5:` и ниже снова `case 5:` вызовет ошибку компиляции.
    
- **Только константы:** В `case` нельзя передавать переменные или диапазоны.
    
    - ❌ `case > 10:` — **Ошибка!**
        
    - ❌ `case x:` (где x — переменная) — **Ошибка!** (Можно, только если `x` объявлена как `final int x = 5;`).
        
- **Ловушка для `String`:** При сравнении строк в `switch` учитывается регистр! `"Зима"` и `"зима"` — это разные вещи для робота. Если в переменной будет `null`, программа вылетит с ошибкой `NullPointerException`.
    

## 4. Новая магия: Switch Expressions (Начиная с Java 14+)

Если ты пишешь код на современной версии Java (не в старых университетских тестировщиках), `switch` превратился в мощный инструмент, который может возвращать значение.

### 🔥 Стрелочный синтаксис (`->`)

Больше никаких `break`! Стрелка автоматически обрывает выполнение. Проваливание здесь не работает.

Java

```java
switch (day) {
    case 1, 2, 5 -> System.out.println("Будний день"); // Перечисление через запятую!
    case 6, 7    -> System.out.println("Выходной!");
    default      -> System.out.println("Неверный день");
}
```

### 💰 Возврат значения в переменную

`switch` можно использовать как обычное выражение и сразу присваивать результат переменной:

Java

```java
String season = switch (month) {
    case 12, 1, 2 -> "Зима";
    case 3, 4, 5  -> "Весна";
    case 6, 7, 8  -> "Лето";
    case 9, 10, 11 -> "Осень";
    default       -> "Ошибка"; // В выражениях default ОБЯЗАТЕЛЕН
}; // Обрати внимание на точку с запятой в конце скобки!
```

### 🧠 Ключевое слово `yield` (Если нужен сложный код внутри)

Если при использовании нового `switch` внутри кейса нужно написать несколько строк кода перед тем, как вернуть значение, используется слово `yield`:

Java

```java
int result = switch (mode) {
    case "fast" -> 1;
    case "slow" -> {
        System.out.println("Выбран сложный режим...");
        int calculation = 10 * 5;
        yield calculation; // Возвращает значение из фигурных скобок
    }
    default -> 0;
};
```

### 💡 Короткий чек-лист для Obsidian:

1. Пишешь в старом тестере (Java 7)? -> Используй **`case 1: case 2: break;`**.
    
2. Забыл `break`? -> Код **провалится** вниз.
    
3. Передаешь диапазоны (`x > 10`)? -> Юзай **`if-else`**, свитч так не умеет.
