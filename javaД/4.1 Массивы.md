## 1. Что такое массив и зачем он нужен

Массив — это **набор переменных одного типа**, лежащих подряд в памяти под одним именем. Вместо того чтобы создавать `int day1, day2, day3, day4, day5, day6, day7` — создаёшь один массив на 7 элементов.

**Главное правило:** все элементы массива — **строго одного типа**. Нельзя смешать `int` и `String` в одном массиве.

---

## 2. Объявление массива

### Шаг 1 — объявить переменную (тип + квадратные скобки)

```java
int[] arr; // переменная "arr" пока ничего не содержит, просто заявили что она БУДЕТ массивом int
```

На этом этапе массив **ещё не создан** — переменная просто "обещает" хранить массив `int` в будущем. Сейчас она равна `null` (то есть пока ни на что не указывает).

### Шаг 2 — создать сам массив через new

```java
int[] arr = new int[5]; // создали массив на 5 элементов
```

`new int[5]` — ключевое слово `new` говорит Java "выдели память под 5 чисел типа `int`, подряд".

⚠️ **Важный нюанс который не упомянут в твоём конспекте:** размер массива задаётся **один раз при создании**, и его **нельзя изменить** позже. Если нужно "увеличить" массив — придётся создавать новый массив и копировать туда данные (об этом ниже отдельно, в разделе про ограничения).

---

## 3. Индексация — нумерация с нуля

```java
int[] arr = new int[5];
arr[2] = 42;

System.out.println(arr[2]); // 42
System.out.println(arr[3]); // 0
```

**Индексация всегда начинается с 0.** Массив из 5 элементов имеет индексы `0, 1, 2, 3, 4` — то есть **последний** индекс это `длина - 1`, а не сама длина.

```
индекс:    0    1    2    3    4
массив: [ 0 ] [ 0 ] [42] [ 0 ] [ 0 ]
```

⚠️ **Частая ошибка новичков** — попытка достать `arr[5]` у массива из 5 элементов:

```java
int[] arr = new int[5];
System.out.println(arr[5]); // ОШИБКА! ArrayIndexOutOfBoundsException
```

Индекса `5` не существует — максимальный это `4`. Это одна из самых частых ошибок в Java вообще, запомни железно: **последний индекс = длина − 1**.

---

## 4. Значения по умолчанию

Когда массив создан через `new`, но конкретные значения не заданы — Java сама заполняет его "пустыми" значениями в зависимости от типа:

|Тип|Значение по умолчанию|
|---|---|
|`int`, `long`, `short`, `byte`|`0`|
|`double`, `float`|`0.0`|
|`char`|`'\0'` (специальный пустой символ, не пробел!)|
|`boolean`|`false`|
|`String` и любые объекты|`null`|

```java
int[] nums = new int[3];
String[] words = new String[3];

System.out.println(nums[0]);  // 0
System.out.println(words[0]); // null
```

⚠️ **Важная деталь про `null`** — если попробуешь вызвать метод на пустом элементе массива объектов (например `words[0].length()`), получишь ошибку `NullPointerException`, потому что там в буквальном смысле "ничего нет", а не пустая строка.

## 5. Инициализация — сразу с конкретными значениями

### Способ 1 — литерал в фигурных скобках (стандартный, используй этот)

```java
String[] names = {"A", "B", "C", "D"};
System.out.println(names[2]); // C
```

Здесь Java сама вычисляет размер массива (тут это `4`) и сразу заполняет его значениями. `new` тут даже не нужен — компактная запись делает это автоматически за тебя.

### Способ 2 — квадратные скобки после имени (устаревший, избегай)

```java
String names[] = {"A", "B", "C", "D"}; // работает, но так писать не принято
```

Твой конспект упомянул это правильно — **в реальном коде почти никто так не пишет**. Стандарт — Способ 1, всегда ставь `[]` сразу после типа, а не после имени переменной.

### Способ 3 (которого в конспекте нет) — полная форма через new с литералом

```java
int[] numbers = new int[]{1, 2, 3, 4, 5};
```

Это та же самая инициализация что и Способ 1, просто более "длинная" запись. На практике встретишь её редко (обычно когда массив передаётся прямо как аргумент в метод), но знать что такое существует полезно.

## 6. Длина массива — атрибут length

```java
int[] newArray = new int[5];
System.out.println(newArray.length); // 5
```

⚠️ **Важнейший нюанс, который твой конспект подчеркнул правильно:** `length` — это **атрибут (поле)**, не метод. Пишется **без круглых скобок**:

```java
System.out.println(newArray.length);   // ПРАВИЛЬНО
System.out.println(newArray.length()); // ОШИБКА компиляции!
```

Это частая путаница, потому что у `String` наоборот — там `length()` это **метод**, с круглыми скобками:

```java
String s = "Привет";
System.out.println(s.length()); // 6 — у String это МЕТОД, со скобками!

int[] arr = {1, 2, 3};
System.out.println(arr.length); // 3 — у массива это АТРИБУТ, без скобок!
```

**Запомни это противоречие железно** — это одна из самых частых синтаксических ошибок у новичков именно из-за того что `String` и массив ведут себя по-разному в этом конкретном моменте.

## 7. Обработка массива через обычный for

Используешь когда нужен **индекс** (например для изменения элементов, или для сравнения соседних элементов):

```java
int[] myArr = {6, 42, 3, 7, 16, 10, 22};
int summ = 0;

for (int x = 0; x < myArr.length; x++) {
    summ += myArr[x];
}

System.out.println(summ); // 106
```

**Почему именно `x < myArr.length`, а не `x <= myArr.length`:** если длина массива `7`, индексы `0...6`. Условие `x < 7` пройдёт значения `0, 1, 2, 3, 4, 5, 6` — ровно те, что существуют. Если написать `x <= myArr.length`, последняя итерация попытается взять `myArr[7]`, которого не существует — `ArrayIndexOutOfBoundsException`.

---

## 8. Обработка массива через for-each (сокращённый цикл)

Используешь когда нужно просто **пройтись по всем элементам**, и индекс **не важен**:

```java
String[] beatles = {"John", "Paul", "Ringo", "George"};

for (String person : beatles) {
    System.out.println(person);
}
```

**Результат:**

```
John
Paul
Ringo
George
```

Читается как "для каждого `person` в `beatles`". На каждой итерации `person` берёт значение очередного элемента массива.

### ⚠️ Главное ограничение for-each, о котором в твоём конспекте не сказано

В for-each **нельзя изменить сам массив** через переменную цикла:

```java
int[] nums = {1, 2, 3};

for (int n : nums) {
    n = n * 2; // это меняет ТОЛЬКО локальную копию n, массив nums не изменится!
}

System.out.println(nums[0]); // всё равно 1, а не 2!
```

Если нужно **изменить** элементы массива — обязательно используй обычный `for` с индексом:

```java
int[] nums = {1, 2, 3};

for (int i = 0; i < nums.length; i++) {
    nums[i] = nums[i] * 2; // теперь реально меняем элемент по индексу
}

System.out.println(nums[0]); // 2 — сработало!
```

**Правило выбора:**

|Что нужно|Какой цикл|
|---|---|
|Просто прочитать/вывести все элементы|for-each|
|Изменить элементы массива|обычный for с индексом|
|Нужен индекс для логики (сравнение соседей, и т.д.)|обычный for с индексом|

## 9. split() — превращение строки в массив

```java
String str = "I'll be back";
String[] words = str.split(" ");

for (String word : words) {
    System.out.println(word);
}
```

**Результат:**

```
I'll
be
back
```

`split(" ")` разрезает строку по пробелу и возвращает массив `String[]`. Аргумент в скобках — это **разделитель**, по которому режется строка:

```java
String dataLine = "158;190;178;186;174";
String[] dataHeight = dataLine.split(";"); // режем по точке с запятой
```

⚠️ **Очень важный момент, который твой конспект правильно подчеркнул:** `split()` **всегда** возвращает `String[]`, даже если в строке были числа. Нельзя напрямую засунуть результат в `int[]`:

```java
String dataLine = "123 16 456 852";
int[] numbers = dataLine.split(" "); // ОШИБКА компиляции! split() даёт String[], не int[]
```

**Правильный способ — конвертировать каждый элемент отдельно** (вспоминаем тему про конвертацию типов, которую разбирали ранее):

```java
String dataLine = "123 16 456 852";
String[] strNumbers = dataLine.split(" ");
int[] numbers = new int[strNumbers.length];

for (int i = 0; i < strNumbers.length; i++) {
    numbers[i] = Integer.parseInt(strNumbers[i]); // конвертируем каждую строку в число
}

System.out.println(numbers[0] + numbers[1]); // 139 — теперь можно математику делать!
```

Это очень частый паттерн в задачах со Stepik — на вход даётся строка чисел через пробел, и нужно превратить в массив `int[]` для дальнейших вычислений.

## 10. Глубина — чего НЕТ в твоём конспекте, но реально нужно знать

### А) Массивы — это объекты, и они хранятся через ссылку

Это важная концептуальная вещь. Когда копируешь массив в другую переменную — копируется **не сам массив**, а только "адрес" (ссылка) на него:

```java
int[] original = {1, 2, 3};
int[] copy = original; // copy указывает на ТОТ ЖЕ массив, а не на новую копию!

copy[0] = 999;

System.out.println(original[0]); // 999! Изменился оригинал тоже!
```

Это сбивает с толку многих новичков — кажется что `copy` это отдельный массив, но на деле обе переменные смотрят на **одни и те же** данные в памяти. Если нужна **настоящая** копия — используй `Arrays.copyOf()` (см. ниже).

### Б) Многомерные массивы (массив массивов)

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

System.out.println(matrix[1][2]); // 6 — вторая строка (индекс 1), третий элемент (индекс 2)
```

Это "таблица" — массив, где каждый элемент сам является массивом. Используется для матриц, игровых полей (например крестики-нолики), таблиц данных. Перебирается вложенным циклом:

```java
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        System.out.print(matrix[i][j] + " ");
    }
    System.out.println();
}
```

Это будущая тема, но раз заговорили про массивы — полезно уже видеть что такое существует.

### В) Полезные методы класса Arrays

Java предоставляет готовый класс-помощник `Arrays` с кучей полезных инструментов (нужен `import java.util.Arrays;`):

```java
import java.util.Arrays;

int[] nums = {5, 2, 8, 1, 9};

// Вывести весь массив сразу, красиво
System.out.println(Arrays.toString(nums)); // [5, 2, 8, 1, 9]

// Отсортировать массив
Arrays.sort(nums);
System.out.println(Arrays.toString(nums)); // [1, 2, 5, 8, 9]

// Настоящая копия массива (не просто ссылка, как в пункте А)
int[] copy = Arrays.copyOf(nums, nums.length);

// Заполнить весь массив одним значением
int[] filled = new int[5];
Arrays.fill(filled, 7);
System.out.println(Arrays.toString(filled)); // [7, 7, 7, 7, 7]

// Найти элемент в ОТСОРТИРОВАННОМ массиве (бинарный поиск)
int index = Arrays.binarySearch(nums, 5);
System.out.println(index); // позиция числа 5 в отсортированном массиве
```

`Arrays.toString()` — это твой лучший друг для **отладки**. Без него `System.out.println(nums)` выведет странную техническую строку типа `[I@1b6d3586`, а не сами числа:

```java
int[] nums = {1, 2, 3};
System.out.println(nums);              // [I@1b6d3586 — бесполезно!
System.out.println(Arrays.toString(nums)); // [1, 2, 3] — то что нужно!
```

### Г) Поиск максимума/минимума в массиве — частый паттерн задач

```java
int[] nums = {5, 2, 8, 1, 9};
int max = nums[0]; // начинаем с первого элемента, а не с 0!

for (int i = 1; i < nums.length; i++) {
    if (nums[i] > max) {
        max = nums[i];
    }
}

System.out.println(max); // 9
```

⚠️ **Важная деталь:** начинай поиск максимума не с `0`, а с **первого элемента массива** (`nums[0]`). Если в массиве все числа отрицательные (например `{-5, -2, -8}`), а ты начнёшь с `max = 0` — получишь неправильный ответ `0`, хотя реального нуля в массиве нет.
