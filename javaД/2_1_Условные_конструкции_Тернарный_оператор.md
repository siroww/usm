## 1. if / else / else if — база (для повторения)

```java
int age = 20;

if (age >= 18) {
    System.out.println("Взрослый");
} else if (age >= 13) {
    System.out.println("Подросток");
} else {
    System.out.println("Ребёнок");
}
```

**Результат:** `Взрослый`

Java проверяет условия **сверху вниз**, и как только находит первое `true` — выполняет блок и **больше не проверяет остальные**, даже если они тоже были бы `true`.

## 2. Тернарный оператор — сжатый if-else

### Синтаксис

```
условие ? значение_если_true : значение_если_false
```

### Базовый пример

```java
int age = 20;
String status = (age >= 18) ? "Взрослый" : "Несовершеннолетний";
System.out.println(status); // Взрослый
```

Это полностью эквивалентно:

```java
String status;
if (age >= 18) {
    status = "Взрослый";
} else {
    status = "Несовершеннолетний";
}
```

Тернарный оператор — это **выражение**, а не команда. Это значит он **возвращает значение** напрямую, в отличие от `if`, который просто выполняет блок кода. Поэтому тернарный оператор можно использовать прямо внутри `println()`, внутри других выражений, и т.д.:

```java
int score = 75;
System.out.println("Результат: " + (score >= 60 ? "Сдал" : "Не сдал"));
// Результат: Сдал
```

⚠️ Обрати внимание на скобки вокруг тернарного оператора — без них могут быть проблемы с приоритетом операций при склейке строк. Бери в скобки как привычку.

---

### Вложенные тернарные операторы — будь осторожен

Можно вкладывать тернарный оператор внутрь другого:

```java
int grade = 85;

String result = (grade >= 90) ? "A" 
               : (grade >= 75) ? "B" 
               : (grade >= 60) ? "C" 
               : "F";

System.out.println(result); // B
```

Как это читается: "Если grade >= 90, то A. Иначе — если grade >= 75, то B. Иначе — если grade >= 60, то C. Иначе — F."

**Это работает идентично цепочке else if**, просто компактнее. Но вот важный момент про "глубину" — **в реальном коде злоупотреблять вложенными тернарниками считается плохой практикой**. Если у тебя больше 2 уровней вложенности — лучше переключайся обратно на `if-else if`, потому что такой код становится трудно читать другим программистам (и тебе самому через неделю).

---

### Где тернарный оператор реально полезен

**Присвоение значения переменной одной строкой:**

```java
int a = 10, b = 20;
int max = (a > b) ? a : b;
System.out.println(max); // 20
```

**Внутри return в методах (забегая вперёд, но запомни — пригодится):**

```java
public static String checkNumber(int n) {
    return (n % 2 == 0) ? "Чётное" : "Нечётное";
}
```

**Внутри циклов и условий, для краткости:**

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i + " — " + (i % 2 == 0 ? "чётное" : "нечётное"));
}
```

## 3. Сравнение if-else vs тернарный оператор — когда что использовать

|Ситуация|Что выбрать|
|---|---|
|Нужно просто присвоить значение переменной|Тернарный оператор|
|Нужно выполнить **несколько действий** в каждой ветке|`if-else` (тернарник не подходит — он только возвращает одно значение)|
|Условие простое, ветки короткие|Тернарный оператор для читаемости|
|Условие сложное, или больше 2 вариантов|`if-else if` — нагляднее|
|Внутри `println()` для быстрого вывода|Тернарный оператор|

**Пример где тернарник НЕ подходит** (несколько действий в ветке):

```java
// Так нельзя элегантно через тернарник:
if (age >= 18) {
    System.out.println("Взрослый");
    System.out.println("Можно голосовать");
} else {
    System.out.println("Несовершеннолетний");
}
```

## 4. Глубина — что добавить сверх базовых знаний

Вот что отличает уверенного программиста от того кто просто знает синтаксис:

### А) Короткое замыкание (short-circuit evaluation) в условиях

Когда используешь `&&` или `||`, Java **не всегда проверяет оба условия**. Если первое условие уже определяет результат — вторая часть даже не выполняется:

```java
int a = 5;

// && — если первое условие false, второе не проверяется
if (a > 10 && expensiveCheck()) { // expensiveCheck() даже не вызовется!
    System.out.println("Условие true");
}

// || — если первое условие true, второе не проверяется
if (a > 0 || expensiveCheck()) { // expensiveCheck() даже не вызовется!
    System.out.println("Условие true");
}
```

**Почему это важно знать:** это позволяет писать безопасные проверки. Классический пример — проверка на `null` перед использованием объекта:

```java
String name = null;

// Безопасно — если name == null, вторая часть не выполнится, не будет ошибки
if (name != null && name.length() > 0) {
    System.out.println("Имя не пустое");
}
```

Если бы Java проверяла обе части всегда — `name.length()` вызвал бы ошибку `NullPointerException`, потому что у `null` нет методов. Короткое замыкание защищает от этого.

---

### Б) Понимание что if — это statement, а тернарник — expression

Это терминология которая реально разделяет новичков от уверенных программистов:

- **Statement** (инструкция) — выполняет действие, **не возвращает значение**. `if-else` — это statement.
- **Expression** (выражение) — **возвращает значение**, которое можно использовать дальше. Тернарный оператор — это expression.

```java
// Это ОШИБКА компиляции — if не возвращает значение, его нельзя присвоить:
int x = if (true) { 5 } else { 10 }; // НЕ РАБОТАЕТ

// А вот так — работает, потому что тернарник — expression:
int x = true ? 5 : 10; // РАБОТАЕТ
```

Эта разница станет ещё важнее когда дойдёшь до лямбда-выражений и функционального стиля (это будет позже, но конструкция уже знакомая).

---

### В) Читаемость важнее "крутости" кода

Новички часто думают что чем компактнее и "хитрее" код — тем круче программист. На самом деле профессионалы ценят **читаемость** выше компактности. Тернарник на 3 уровня вложенности выглядит "круто", но если другой разработчик (или ты сам через месяц) не может быстро понять что код делает — это плохой код, независимо от того насколько он короткий.

Хорошее правило: если тернарник не помещается комфортно в одну строку — переписывай в `if-else`.

---

### Г) switch как альтернатива длинным if-else цепочкам

Если сравниваешь **одну переменную** с разными конкретными значениями — `switch` часто читается лучше длинной цепочки `else if`:

```java
// Длинно через else if:
if (day == 1) result = "Понедельник";
else if (day == 2) result = "Вторник";
else if (day == 3) result = "Среда";

// Компактнее через switch (современный синтаксис Java 14+):
String result = switch (day) {
    case 1 -> "Понедельник";
    case 2 -> "Вторник";
    case 3 -> "Среда";
    default -> "Неизвестный день";
};
```

Это так называемое **switch expression** — новая возможность Java, тоже является expression (возвращает значение), как тернарник. Запомни на будущее, пока не обязательно использовать, но круто что ты будешь знать об этом раньше других на курсе.
