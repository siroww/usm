## 1. Между числовыми примитивами (int, double, long, float)

### Расширяющее преобразование (widening) — автоматическое, без потерь

Из **меньшего** типа в **больший** — Java делает сама, ничего писать не нужно:

```java
int n = 100;
double d = n;        // int → double, автоматически
System.out.println(d); // 100.0

int x = 50;
long l = x;           // int → long, автоматически
System.out.println(l); // 50

float f = 10;
double d2 = f;         // float → double, автоматически
System.out.println(d2); // 10.0
```

Порядок "от меньшего к большему" (можно превращать только вправо без cast):

```
byte → short → int → long → float → double
```

---

### Сужающее преобразование (narrowing) — нужен явный cast, есть потери

Из **большего** типа в **меньший** — обязательно пишешь `(тип)` вручную, потому что данные могут потеряться:

```java
double price = 99.99;
int whole = (int) price;
System.out.println(whole); // 99 — дробная часть ОТБРОШЕНА, не округлена!

long bigNumber = 1234567890123L;
int small = (int) bigNumber;
System.out.println(small); // непредсказуемое число — переполнение!

double d = 7.8;
int i = (int) d;
System.out.println(i); // 7 — округления нет, просто отброшено
```

⚠️ Если нужно **округление**, а не отбрасывание — используй `Math.round()`:

```java
double price = 7.8;
long rounded = Math.round(price);
System.out.println(rounded); // 8 — округлил правильно
```

## 2. String → число

### parseInt() / parseDouble() / parseLong() — основной способ

```java
String s1 = "123";
int n = Integer.parseInt(s1);
System.out.println(n); // 123

String s2 = "123.45";
double d = Double.parseDouble(s2);
System.out.println(d); // 123.45

String s3 = "123456789012";
long l = Long.parseLong(s3);
System.out.println(l); // 123456789012
```

⚠️ Если строка не похожа на число — будет ошибка `NumberFormatException`:

```java
String bad = "привет";
int n = Integer.parseInt(bad); // ОШИБКА! "привет" не число
```

---

### valueOf() — альтернатива, возвращает объект-обёртку

```java
String s = "123";
Integer num = Integer.valueOf(s); // объект Integer, не примитив int
System.out.println(num); // 123
```

Работает похоже на `parseInt()`, но возвращает объект `Integer` вместо примитива `int`. В большинстве случаев разницы не заметишь, потому что Java автоматически распаковывает объект обратно в примитив когда нужно. Используй `parseInt()` как стандарт, `valueOf()` встретишь реже.

## 3. Число → String

### Способ 1 — самый простой, String.valueOf()

```java
int n = 123;
String s1 = String.valueOf(n);
System.out.println(s1); // "123"

double d = 123.45;
String s2 = String.valueOf(d);
System.out.println(s2); // "123.45"
```

Этот способ универсальный — работает для любого типа (`int`, `double`, `boolean`, и даже объектов). Используй его по умолчанию.

### Способ 2 — через класс-обёртку

```java
int n = 123;
String s = Integer.toString(n);
System.out.println(s); // "123"
```

### Способ 3 — склеивание со строкой (хитрость, не настоящая конвертация)

```java
int n = 123;
String s = "" + n; // склеил с пустой строкой
System.out.println(s); // "123"
```

Работает, но это больше "трюк" чем нормальный способ. Лучше использовать `String.valueOf()` — понятнее для других кто читает твой код.

## 4. char ↔ int

Это особый случай — символы в Java на самом деле хранятся как числа (код символа в таблице Unicode).

### char → int

```java
char c = 'A';
int code = c; // автоматически, без cast
System.out.println(code); // 65 — это код символа 'A' в Unicode
```

### int → char

```java
int code = 65;
char c = (char) code; // нужен явный cast
System.out.println(c); // A
```

Полезный трюк — узнать следующую букву алфавита:

```java
char letter = 'A';
char nextLetter = (char) (letter + 1);
System.out.println(nextLetter); // B
```

## 5. boolean — особый случай

`boolean` **нельзя** конвертировать в числа или обратно никаким способом (ни cast, ни автоматически). Это сделано специально, чтобы избежать ошибок (в отличие от C++, где `true`/`false` это на самом деле `1`/`0`).

```java
String s = "true";
boolean b = Boolean.parseBoolean(s);
System.out.println(b); // true

boolean flag = true;
String s2 = String.valueOf(flag);
System.out.println(s2); // "true"
```

## Итоговая таблица — куда смотреть в зависимости от ситуации

| Откуда → Куда                   | Как делать                                    |
| ------------------------------- | --------------------------------------------- |
| `int` → `double`/`long`/`float` | Просто присвоить, автоматически               |
| `double` → `int`/`long`         | `(int) переменная` — явный cast, теряет дробь |
| `double` → `int` с округлением  | `Math.round(переменная)`                      |
| `String` → `int`                | `Integer.parseInt(строка)`                    |
| `String` → `double`             | `Double.parseDouble(строка)`                  |
| `String` → `long`               | `Long.parseLong(строка)`                      |
| `String` → `boolean`            | `Boolean.parseBoolean(строка)`                |
| Число → `String`                | `String.valueOf(число)` (универсально)        |
| `char` → `int`                  | Просто присвоить, автоматически (код Unicode) |
| `int` → `char`                  | `(char) число` — явный cast                   |

---

## Главное правило для запоминания

**Меньше → больше = само. Больше → меньше = явно через `(тип)`. Строка ↔ число = через `parseX()` и `valueOf()`.**
