## Первая программа

Каждая программа на Java начинается вот так:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Привет, мир!");
    }
}
```

**Что здесь происходит:**

`public class Main` — это класс, контейнер для твоего кода. Имя файла должно совпадать с именем класса — то есть файл называется `Main.java`

`public static void main(String[] args)` — это главный метод, точка входа. Когда запускаешь программу — Java первым делом ищет именно этот метод и начинает выполнение с него

`System.out.println()` — выводит текст в консоль и переходит на новую строку

**Результат в консоли:**

```
Привет, мир!
```

## Переменные и типы данных

Переменная — это коробка с именем, в которую ты кладёшь какое-то значение.

В Java у каждой коробки есть **тип** — то есть ты заранее говоришь что туда положишь: число, текст, или что-то ещё.

### Основные типы:

```java
public class Main {
    public static void main(String[] args) {

        // Целое число
        int age = 19;

        // Число с точкой (дробное)
        double price = 99.99;

        // Один символ
        char letter = 'A';

        // Правда или ложь
        boolean isStudent = true;

        // Текст (строка)
        String name = "Артемий";

        System.out.println(age);       // 19
        System.out.println(price);     // 99.99
        System.out.println(letter);    // A
        System.out.println(isStudent); // true
        System.out.println(name);      // Артемий
    }
}
```

**Важные моменты:**

- `int`, `double`, `char`, `boolean` — пишутся с маленькой буквы, это примитивные типы
- `String` — пишется с большой буквы, это уже объект
- Текст в `String` пишется в двойных кавычках `"текст"`, а символ в `char` в одинарных `'A'`
- В конце каждой строки кода ставится `;`

## Арифметические операторы

```java
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 3;

        System.out.println(a + b);  // 13 — сложение
        System.out.println(a - b);  // 7  — вычитание
        System.out.println(a * b);  // 30 — умножение
        System.out.println(a / b);  // 3  — деление (внимание!)
        System.out.println(a % b);  // 1  — остаток от деления
    }
}
```

**Важный момент про деление:**

`10 / 3` даёт `3`, а не `3.33` — потому что оба числа целые (`int`), и Java отбрасывает дробную часть. Чтобы получить `3.33` — нужно использовать `double`:

```java
double result = 10.0 / 3;
System.out.println(result); // 3.3333333333333335
```

## Вывод текста с переменными

```java
public class Main {
    public static void main(String[] args) {
        String name = "Артемий";
        int age = 19;

        // Способ 1 — склеивание через +
        System.out.println("Меня зовут " + name + " и мне " + age + " лет");

        // Способ 2 — через printf (удобнее когда переменных много)
        System.out.printf("Меня зовут %s и мне %d лет%n", name, age);
    }
}
```

**Результат обоих способов одинаковый:**

```
Меня зовут Артемий и мне 19 лет
```

`%s` — место для строки, `%d` — место для целого числа, `%n` — новая строка.

## основа для лабораторки
```java
class Studnet {
	String name;    // 
	Float lazynass; // коэфициент лени от 0-1 где 1 это ленивый
	Byte IQ;        // (максимальное значение 127) 80-127 
	int exams;      // кол-во экзаменов
	int marks[]     // кол-во оценок
	
	Studnet () {    // конструктор класса студент
		name = "Pantera";
		lazynass = (FLoat)0.67; // 0.67f
		IQ = (Byte)127;
		exams = 6;
		marks = new int[exams];
		for(int i = 0; i < exams; i++) {
			marks[i] = 7;
		}
	}
	
	Student (Float lazynass, Byte iq) { // конструктор с параметром
		name = "Erick";
		this.lazynass = lazynass; // чтобы небыло конфликта надо использовать this
		IQ = iq; // конфликта имён не будет так как разные регистры
		exams = 18;
		marks = new int[exams];
		for(int i = 0; i < exams; i++) {
			marks[i] = 8;
		}
	}
	
	Studnet (Studnet other) {    // конструктор копирования
		name = other.name;
		lazynass = other.lazynass;
		IQ = other.IQ;
		exams = other.exams;
		marks = new int[exams];
		for(int i = 0; i < exams; i++) {
			marks[i] = other.marks[i];
		}
	}
	
	void echo() {
		System.out.println("name: " + this.name);
		System.out.println("lazynass: " + this.lazynass);
		System.out.println("IQ: " + this.IQ);
		System.out.println("exams: " + this.exams);
		// вывод массива
		for (int i; i < exams; i++) {
			System.out.print(" " + this.exams[i]);
		}
	}
	
}
```
